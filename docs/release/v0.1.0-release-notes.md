# Sothoth 0.1.0 release notes

**Status: 0.1.0 release candidate — pre-publication.** These notes describe the candidate built from this repository. Sothoth `0.1.0` is **not yet published on npm**: no package of this release exists on the registry yet, and the local evidence below is repository evidence only, not publication evidence.

## What this release is

Sothoth is a deterministic governance control plane for exact design facts. The `0.1.0` candidate comprises exactly the eleven members of the formal Scope BOM `SOTHOTH-RELEASE-SCOPE-BOM-0.1@4` (`docs/release/v0.1.0-scope-bom.json`), all at version `0.1.0`, all Apache-2.0:

| Package | Responsibility |
|---|---|
| `@project-sothoth/contracts` | Closed public contracts (identities, schemas, diagnostics, projections, extensions); zero runtime dependencies. |
| `@project-sothoth/core` | Pure deterministic kernel: canonical JSON, SHA-256, code-point order, diagnostics, outcome aggregation, exit mapping. |
| `@project-sothoth/graph` | Meaning-free directed multigraph algorithms (traversal, SCC, condensation, waves, longest paths). |
| `@project-sothoth/document-index` | Deterministic CommonMark structural indexing over the pinned `mdast-util-from-markdown@2.0.2` parser. |
| `@project-sothoth/selectors` | Closed declarative selector algebra with deterministic matching, cardinality, and explain. |
| `@project-sothoth/governance` | Registry/ledger validation, pre-design closure, Scope BOM admissibility, change plans, gate macros. |
| `@project-sothoth/planning` | Dependency-constraint validation and deterministic topological wave schedules. |
| `@project-sothoth/profile-sdk` | Consumer-neutral Consumer Profile contract, loading, and conformance. |
| `@project-sothoth/git` | Read-only Git source snapshots behind a frozen subcommand allowlist. |
| `@project-sothoth/sdk` | Sole aggregate public library facade. |
| `@project-sothoth/cli` | Eight explicit commands, atomic explicit output, frozen exit mapping. |

See the [package references](../packages/contracts.md) under `docs/packages/` for per-package surfaces, and [ARCHITECTURE.md](../../ARCHITECTURE.md) for the manifest-verified dependency DAG.

## What the candidate carries

- Closed public surfaces: every package's exports map equals its accepted Dossier `public-surface-declaration@1`; unauthorized specifiers fail with `ERR_PACKAGE_PATH_NOT_EXPORTED`.
- Deterministic compilation: canonical bytes, digest-bearing projections, budgeted hostile-input rejection, and Structured Diagnostics throughout.
- Release-packaging evidence generated locally by `npm run release:verify` into gitignored `dist/release/`: two reproducible packs of all eleven packages with byte-identical tarballs and SHA-512 digests (hex and SRI representations kept distinct), a CycloneDX SBOM that includes the MIT `mdast-util-from-markdown@2.0.2` / `micromark@4.0.2` parser subtree alongside the Apache-2.0 workspace packages, the pre-publication Candidate BOM bound to the clean source commit and Scope BOM `@3`, and an offline CLI install smoke using only the local tarballs.

## Known limitations

- Not published: every `npm install @project-sothoth/*` command remains unavailable until the publication step runs.
- The CLI ships exactly eight commands; planning implements the dependency-wave dimension only; document indexing is CommonMark-structural only.
- Publication evidence is **pending** for `@project-sothoth/contracts@0.1.0`, `@project-sothoth/governance@0.1.0`, `@project-sothoth/profile-sdk@0.1.0`, and `@project-sothoth/sdk@0.1.0` — the four FRACTA-facing generic packages. It is satisfied only by records taken from the live npm registry by the publication task; nothing in this repository can substitute for it.
- `@fracta/sothoth-profile` is a companion FRACTA Release Train and is never published from this repository; this release contains no FRACTA adapters, policies, or runtime integration.
- Toolchain note: the candidate environment ran npm `11.11.0` against a declared `packageManager` of `11.15.0`; the drift is recorded, not reconciled.
